# Bank-Customer-Churn-Analysis-Dashboard
This project presents an interactive Customer Churn Analysis Dashboard built using Microsoft Power BI. The objective is to analyze customer behavior, identify factors associated with customer churn, and provide business insights that can help improve customer retention.

The dashboard enables users to explore churn patterns across customer demographics, credit profiles, geographics regions, and account information through interactive visualizations.

Note: This project was developed as part of a guided Power BI learning project and has been documented and customized to demonstrate my understanding of data modeling, DAX, and dashboard design.

## Objectives
- Analyze customer churn trends
- Identify customer segments with higher churn rates
- Explore demographic and financial factors influencing churn
- Build an interactive dashboard for business users
- Practice Power BI data modeling and DAX calculations

## Dataset

The project uses a bank customer churn dataset containing customer information such as:

- Customer demographics
  
- Gender
- Geography
- Active membership status
  
- Financial information
  
- Credit score
- Credit category
- Account balance
  
- Customer relationship information
  
- Date joined
- Tenure
- Exit status

The dataset is used solely for educational and portfolio purposes.

## Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)

# Project Workflow

## 1. Data Import

- Imported customer data into Power BI
- Reviewed dataset structure
- identified fact and dimension tables

## 2. Data Cleaning & Transformation

Using Power Query:

- Removed unnecessary columns
- Checked data quality.
- Prepared data for analysis
- Created a Date Master table for time-based analysis
- Built relationships between tables

## 3. Data Modeling

Created relationships between:

- Customer data
- Geography
- Date table
- Creadit categories

implemented a star-schema style model to improve reporting.

## 4. DAX Calculations

Created calculated columns and measures including:

- Credit Type classification
- Exit Customer metrics
- Monthly churn comparison
- Time intelligence calculations

## 5. Dashboard Development

Designed an interactive dashboard with:

- KPI cards
- Clustered column charts
- Line charts
- Donut charts
- Bar charts
- Interactive slicers

## Dashboard Features

Interactive filters include:

- year
- Month
- Geography
- Gender
- Customer status
- Active Category

key visualizations include:

- Customer distribution over time.
- Monthly customer exits
- Churn by gender
- Churn by credit category
- Customer trends using drill-down functionality

## Key Insights

Some observations from the analysis include:

- Female customers showed a higher churn rate than male customers.
- Customers with excellent credit scores had the lowest churn rate.
- Monthly churn trends revealed periods with increased customer exits.
- Intereactive filtering enables comparison across different customer segments and geographic regions
